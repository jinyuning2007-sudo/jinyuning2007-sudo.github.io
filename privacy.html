Privacy policy

This policy describes the personal-use Immich Encrypted Backup utility and this informational website. The operator is the owner of the Google account that authorizes the application.

Data accessed and its purpose

The utility reads the operator’s selected local photos, videos, companion files and application recovery metadata to create encrypted recovery copies. It uses Google Drive file identifiers, names, sizes, available storage information and API responses to create, resume, verify and restore those copies.

The Google permission requested is https://www.googleapis.com/auth/drive.file. This permits access to files created by or explicitly made available to this application; it does not grant general access to unrelated Drive files. The utility is configured to work with its dedicated backup repository.

Encryption and credential storage

Backup contents, original filenames and recovery metadata are encrypted locally by Restic before upload. The encryption password and Google authorization credentials are stored with restricted access on the operator’s computer. The utility does not upload the plaintext encryption password as part of the backup.

Google can still receive account and authorization information, network information and ordinary storage metadata such as encrypted object sizes and upload times. Encryption does not conceal all service metadata.

Use, sharing and limited use

Google user data is used only to provide the operator’s backup, verification and recovery functions. The utility does not sell Google user data, use it for advertising, use it to train AI models or disclose backup contents to another recipient. Google processes the stored encrypted files under its own terms and privacy policy.

The application’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and revocation

Recovery points are retained indefinitely unless the operator decides to remove them. Temporary local backup material is removed after successful verification, while settings, credentials and operational records needed to run and recover the backup remain locally.

The operator can revoke application access through their Google Account. Revoking access does not itself delete previously uploaded backups. The operator can manage those files directly in their Drive. Recovery requires the encryption password; losing it can make the encrypted data unrecoverable.

This informational website

These pages contain no login form, application analytics, advertising, tracking scripts or access to the backup repository. The website hosting provider may process standard request information under its own privacy practices.

Questions or changes

Contact the operator using the support address shown on Google’s authorization screen. This policy will be updated if the utility’s data practices change.
